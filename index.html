ANTES DE PRODUÇÃO

Segurança e infraestrutura

Requisitos para transformar o protótipo em serviço real.

1. Login e permissões

Autenticação no backend, senhas com hash forte, sessões seguras e papéis owner/admin/cliente.

2. API privada para o host

Nunca exponha credenciais de administrador, RDP ou tokens no navegador. Use um agente autenticado e limitado.

3. Isolamento de clientes

Limites de CPU/RAM/disco, firewall, redes separadas e controle de acesso a arquivos.

4. Infraestrutura real

É necessário um host compatível com virtualização para VPS Windows e/ou um host para FXServer. Uma página web sozinha não cria VPS.

5. Pagamentos e dados

Integração com provedor de pagamentos via backend, validação de webhooks, backups e política de privacidade.
